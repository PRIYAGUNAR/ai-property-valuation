# AI Property Valuation

A responsive React frontend demo for the AI/ML Engineer Intern practical assignment.

## Features
- Select an image from your device
- Preview the selected image before analysis
- Validate that an image has been selected
- Display sample property type, estimated area, condition, and illustrative value
- Responsive layout for mobile and desktop
- No backend, database, or AI model required

## Tech stack
- React
- Vite
- CSS
- Lucide React icons

## Run locally
You need Node.js installed on a computer.

1. Extract/download this project.
2. Open the project folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Try it on a phone (beginner-friendly)
You can import this project into an online coding workspace that supports React/Vite and a terminal. Upload/extract the project files, run `npm install`, then `npm run dev` using the workspace's preview feature.

## GitHub submission
Create a public repository named `ai-property-valuation`, then upload the project files and folders. Do not upload `node_modules`. Include this README and a screenshot of the completed page.

## Important note
This is a frontend demo. The analysis values are hard-coded examples and are not actual AI predictions or a professional property valuation.
